mockup (화면 단위)

여정 단위로 전환되기 전의 화면 단위 산출물. 전환이 끝나면 이 구획은 사라지고 위 여정 행의 mockup 링크가 채워진다.

화면 단위 mockup 갤러리 M-J1-S1 ~ M-J4-S6 · 27개 화면 + 갤러리 갤러리 열기 → mockup 인덱스
이 페이지는 손으로 갱신한다. 여정·mockup·문서가 늘거나 줄면 같은 커밋에서 이 파일도 고친다.
